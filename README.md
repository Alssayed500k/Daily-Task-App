## 📝 نبذة عن المشروع (Overview)

تطبيق **Daily Task** هو أداة بسيطة وفعالة تهدف إلى مساعدة المستخدم في تنظيم ومتابعة المهام اليومية (To-Do List). يوفر التطبيق واجهة مستخدم سهلة لتسجيل المهام، تعديلها، متابعة حالة إنجازها، وحساب نسبة التقدم اليومية بشكل آلي.

---

## ✨ المميزات الرئيسية (Key Features)

- ➕ **إضافة مهام جديدة:** إمكانية إضافة مهام سريعة مع التحقق من صحة المدخلات.
- ✏️ **تعديل المهام:** مرونة في تحديث نصوص المهام القائمة بعد تحديدها.
- 🗑️ **حذف وإلغاء:** إمكانية حذف مهمة محدودة أو مسح جميع المهام بضغطة زر.
- ☑️ **تحديد سريع:** أزرار مخصصة لتحديد كافة المهام أو إلغاء تحديدها دفعة واحدة.
- 📊 **مؤشر نسبة الإنجاز:** حساب تلقائي لنسبة المهام المكتملة وشريط تقدم (`ProgressBar`) يعكس مستوى الأداء.
- 💾 **حفظ وتخزين محلي:** حفظ تلقائي لحالة المهام (مكتملة / غير مكتملة) وتخزينها في ملف نصي محلي (`Daily Task.txt`) لاسترجاع البيانات عند إعادة فتح التطبيق.
- 🔗 **روابط التواصل:** أزرار سريعة للوصول إلى الحسابات الشخصية للمطور على GitHub و LinkedIn.

## 🛠️ التقنيات والمفاهيم البرمجية (Tech Stack & Concepts)

### التقنيات المستعملة:
- **اللغة البرمجية:** #C (C-Sharp)
- **إطار العمل:** .NET Framework / Windows Forms (WinForms)
- **بيئة التطوير:** Visual Studio

### المفاهيم المطبقة في الكود:
- **إدارة أحداث واجهة المستخدم (Event-Driven Programming):** مثل `ItemCheck`, `Click`, و `TextChanged`.
- **التعامل مع نظام الملفات (File I/O):** استخدام `StreamReader`, `File.AppendAllText`, و `File.Delete` لحفظ واسترجاع البيانات.
- **التعددية والمزامنة (UI Threading):** استخدام `BeginInvoke` لتحديث الواجهة وحفظ البيانات بمرونة دون تجميد الواجهة.
- **استخدام التعدادات (Enums):** لتحديد أوضاع العمل بين الإضافة والتعديل (`enCompoBoxMode`).
- **معالجة الاستثناءات (Error Handling):** استخدام كتلة `try...catch` للتعامل مع الأخطاء غير المتوقعة وعرض تنبيهات توضيحية.
